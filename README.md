# 온소리 팀 공유 현황 보고 페이지

팀원에게 온소리 자막 in YouTube의 수정 과정, 현재 상태, 앞으로의 업데이트 계획을 설명하는 보고용 웹페이지입니다. 실제 온소리 프로그램(Chrome 확장 프로그램)이 아닙니다.

## 여는 법

- **웹 주소로 보기:** https://ny-colab.github.io/onsori-team-report/ (설치·로그인 없이 브라우저에서 30쪽 전체를 볼 수 있습니다. 특정 쪽은 주소 끝에 `#p13`처럼 붙입니다.)
- `index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 열립니다.
- 설치, 서버 실행, 로그인, 인터넷 연결이 필요 없습니다. 글·그림·조작이 모두 파일 하나에 들어 있습니다.
- **한 쪽씩 넘겨 보는 보고서**입니다(30쪽). 아래 재생 막대의 ‘다음’·‘이전’ 버튼, 키보드 → ← (Home·End), 휴대전화에서는 옆으로 밀어 넘깁니다. 막대의 칸을 누르거나 위쪽 ‘목차’에서 원하는 쪽으로 바로 갈 수 있습니다.
- 쪽마다 맨 아래 ‘한 줄’ 요약이 있습니다. 내용이 화면보다 길면 ‘아래에 내용이 더 있어요’ 표시가 나타납니다.
- 특정 쪽을 공유하려면 주소 끝에 `#p13`처럼 쪽 번호를 붙입니다.
- 인터넷이 연결된 경우에만 ‘참고 자료’의 외부 공식 출처 링크가 열립니다. 본문을 읽는 데는 필요하지 않습니다.

## 공유하는 법

- `index.html` 파일 하나만 메신저·메일·공유 드라이브로 전달하면 됩니다(약 1.2MB).
- 웹 주소(GitHub Pages)는 **누구나 열 수 있는 공개 페이지**입니다. 실제 시험 화면 일부와 시험 영상 제목이 들어 있으니, 내리거나 바꿀 일이 생기면 저장소 `NY-colab/onsori-team-report`에서 고치거나 Pages를 끄면 됩니다.
- 고친 뒤 웹 주소에 반영하려면 이 폴더에서 `git add -A`, `git commit`, `git push` 하면 1~2분 뒤 바뀝니다.
- PDF가 필요하면 페이지 위쪽의 **인쇄 · PDF로 저장** 버튼을 누르고 ‘PDF로 저장’을 고르세요. 30쪽이 A4 가로로 한 쪽씩 차례대로 인쇄되고, 메뉴·버튼은 빠지며 접혀 있던 ‘자세히 보기’ 내용도 함께 인쇄됩니다(약 34장).

## 고칠 때

새 소식이 생기면 아래 부분을 고쳐 다시 공유합니다.

| 상황 | 고칠 곳 |
| --- | --- |
| 지원 자원 승인 안내가 옴 | 1쪽 ‘지원 자원’, 22쪽 ‘신청한 세 가지 도구’의 승인 대기 표시, 25쪽 경로 비교, 26쪽 ‘승인 전에 준비한 것’ |
| 새 실제 시험 결과가 나옴 | 13·14쪽(확인한 것·남은 문제), 1쪽 ‘현황 기준’ 날짜 |
| 개선이 제품에 들어감 | 19쪽 개선 목표의 상태 표시, 10·12쪽 표 |
| 일정이 지나감 | 3쪽 ‘지금 어디쯤 와 있나요’ 진행 막대(완료 단계·‘지금’ 표시) |
| 팀 결정이 내려짐 | 28쪽 질문을 결정 내용으로 바꾸기. 실증 방식·80% 정의가 정해지면 15·16·18쪽에 결정 내용 추가 |

- 문장 줄바꿈: 빌드할 때 본문 문장마다(마침표·물음표·느낌표 뒤) 자동으로 줄을 바꿉니다. 원본에는 문장을 이어서 쓰면 됩니다.
- 글만 고칠 때는 `index.html`을 메모장·VS Code 등으로 열어 해당 문장을 찾아 바꾸면 됩니다. 이미지 부분(`data:image/...`로 시작하는 아주 긴 문자열)은 건드리지 마세요.
- 쪽 하나는 `<section class="page" data-chapter="…" data-title="…">` 한 덩어리입니다. 쪽을 더하거나 빼면 쪽 번호·재생 막대·목차는 자동으로 다시 매겨집니다.
- 개발 담당자는 원본 `work/onsori/team-report-build/index.template.html`을 고친 뒤 그 폴더에서 `node build.mjs`를 실행하면 이미지가 들어간 `index.html`이 다시 만들어집니다. 빌드 때 로컬 경로·외부 파일 참조가 섞였는지도 검사합니다.
- 상태 표시는 색과 함께 글자(제품에 적용 / 연결 준비 완료 / 승인 대기 / 추가 개발·검증 예정)로 구분합니다. 근거 없이 ‘완성’, ‘모든 영상 지원’, 정확도 수치를 넣지 않습니다.
